      How to use

      使い方とコツ

      うまく使うコツ

      • ノイズ除去や音量調整をする前の、収録したままのファイルを入れてください。処理済みのファイルだと、声の高い音がすでに削られていて、こもりを直しきれません。
      • m4aをWAVに変換してから入れる必要はありません（変換しても音質は上がりません）。
      • 30分の音声で3〜5分ほどかかります。処理中はこのタブを開いたままにしてください。
      • 長い音声はパソコン（Chrome・Edge・Safari）がおすすめです。スマートフォンではメモリ不足で止まることがあります。
      • 書き出したWAVをAudacityなどで編集するときは、ノイズ除去やノーマライズを重ねてかけないでください。
      • 初回だけAIエンジン（約34MB）を読み込みます。2回目からはブラウザに保存されたものを使います。

      「クリア」と「ナチュラル」

      • クリア：雑音をしっかり消し、声の輪郭をはっきりさせます。迷ったらこちら。
      • ナチュラル：部屋の空気感を少し残し、強調も控えめにします。

      中で行っていること

      1. 読み込み：48kHz・モノラルに揃えます。
      2. 音割れ修復：波形の頭が切れた部分を補間して作り直します。
      3. 雑音の除去：音声専用AI（DeepFilterNet3）で、声と雑音を分けて雑音だけを取り除きます。
      4. 音量の均一化：話している部分だけを見て、話し手ごとの音量差を揃えます。
      5. こもり補正：80Hz以下をカットし、250Hzを下げ、3kHzと5kHz以上を持ち上げ、軽くコンプレッサーをかけます。
      6. 仕上げ：Podcast標準の -16 LUFS に合わせ、ピークを -1.5dBTP 以下に抑えます。
      7. 書き出し：配信用MP3（44.1kHz・128kbps）と編集用WAV（48kHz・16bit）。

      使用しているオープンソース：DeepFilterNet3（MIT / Apache-2.0）、lamejs（LGPL-3.0, LAME）。ライセンス表記
